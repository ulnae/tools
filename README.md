# tools

一个纯前端的工具箱项目，整合了三类常用小工具：文件传输、小说阅读和共享地图标点。项目没有后端服务，所有功能都运行在浏览器端，适合静态托管部署，如 GitHub Pages。

## 项目概览

该仓库以 `index.html` 作为入口页面，提供三种功能入口：

- 文件传输助手：支持电脑与手机之间的点对点文件传输
- 小说阅读器：本地导入 txt 小说，按章节阅读并保存进度
- 共享标点：在地图上标记地点，并按类型筛选/搜索

## 功能介绍

### 1. 导航中心

入口文件：`index.html`

这是整个项目的主入口页面，采用简洁的卡片式导航设计，展示三个工具入口：

- `文件传输助手`
- `小说阅读器`
- `共享标点`

页面样式使用纯 CSS，支持响应式布局，适合桌面端和移动端访问。

### 2. 文件传输助手

入口文件：`transfer.html`

功能特点：

- 基于 WebRTC 点对点连接实现文件直传
- 支持电脑 ↔ 手机之间传输文件
- 可通过二维码扫描进行连接，也支持手动输入对方 ID
- 支持多文件拖拽上传
- 传输时显示进度条和状态信息
- 接收文件后可直接下载保存

实现说明：

- 使用 PeerJS 作为 WebRTC 封装库
- 通过 `location.hash` 的方式支持手机扫码直连
- 通过 `File` API、`Blob` 和 `ArrayBuffer` 处理大文件分片传输
- 采用缓冲区控制和分块发送，减少网络拥塞和卡顿

适用场景：

- 手机向电脑发送照片、视频、文档
- 电脑与手机之间临时文件互传
- 不依赖服务器中转，适合局域网或公网快速传输

### 3. 小说阅读器

入口文件：`reader.html`

功能特点：

- 支持导入 `.txt` 小说文件
- 自动识别章节标题并拆分章节
- 支持前后章节切换
- 支持字体缩放
- 支持深色模式切换
- 支持目录跳转
- 记录阅读进度，重新打开时恢复到上次章节

实现说明：

- 使用 IndexedDB 本地存储小说数据和阅读进度
- 通过文本解析规则识别常见章节标题，如：
  - `第X章`
  - `第X回`
  - `第X节`
  - `【标题】`
  - `---标题---`
- 小说文件内容会按段落展示，保留中文排版效果

适用场景：

- 本地小说管理
- 手机端轻量阅读
- 断点续读体验

### 4. 共享标点地图

入口文件：`marker.html`

功能特点：

- 基于 Leaflet 实现地图展示与交互
- 支持搜索地点名称或描述
- 支持按类型筛选标记点
- 支持新增/管理标记类型
- 支持添加地理位置标点
- 支持点击标点查看详情并跳转导航
- 支持按类别展示不同颜色的标记

数据层：

- `data/markers.geojson`：存放地图标记数据
- `data/types.json`：存放类型定义和颜色配置

实现说明：

- 使用 GitHub API 读取/更新远程 JSON 文件
- 使用 AES-GCM 加密和 PBKDF2 进行 token 保护
- 支持地图定位和导航链接生成（高德导航 URL）
- 使用 IP 定位兜底，增强首次打开时的地图中心定位体验

适用场景：

- 规划旅行路线
- 记录常用地点
- 团队共享地图标记
- 标注餐厅、景点、停车点等

## 技术栈

- HTML：页面结构
- CSS：样式与布局
- JavaScript：业务逻辑与交互
- IndexedDB：本地持久化
- WebRTC / PeerJS：点对点数据传输
- Leaflet：地图渲染
- GitHub API：静态数据同步

## 使用方式

### 方式一：直接打开页面

在浏览器中直接打开以下任一文件：

```bash
index.html
transfer.html
reader.html
marker.html
```

### 方式二：本地静态服务器

```bash
git clone https://github.com/ulnae/tools.git
cd tools
python3 -m http.server 8000
```

然后访问：

```text
http://localhost:8000
```

## 说明

这个项目的重点不是大型工程化应用，而是把几类实用的小工具整合在一个静态站点中，强调：

- 纯前端实现
- 轻量部署
- 交互体验友好
- 多端适配

它更像是一个“工具集合”而非传统业务系统，适合演示前端能力、浏览器 API 应用和轻量静态网站实践。
