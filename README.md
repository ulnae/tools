# 工具箱

一个纯前端的静态工具集合，面向日常使用场景，集中展示一组轻量、实用、无需后端服务的网页工具。项目以 `index.html` 作为入口，提供多项工具的快捷入口，并通过浏览器本地能力完成数据处理、存储和交互。

## 主要功能

### 1. 入口首页：`index.html`

这是整个项目的主入口。首页采用现代化的卡片式布局，展示一组常用工具入口，并结合日期、农历和时辰信息增强展示效果。

主要特点：

- 以工具卡片方式集中展示各功能入口
- 支持浅色/深色模式自动切换
- 适配手机端和桌面端布局
- 通过静态页面实现轻量导航中心

### 2. 文件传输助手：`transfer.html`

这是一个基于 WebRTC 的点对点文件传输工具，可以在同一局域网或通过稳定连接环境下，进行电脑和手机之间的文件直传。

核心能力：

- 电脑 ↔ 手机直接建立 P2P 连接
- 不依赖服务器中转，文件在浏览器端直传
- 支持多文件选择与拖拽上传
- 传输中显示进度与状态信息
- 接收后可直接下载保存

技术实现：

- 使用 PeerJS 封装 WebRTC 连接
- 通过二维码或手动输入 ID 建立连接
- 使用 `File`、`Blob` 与 `ArrayBuffer` 处理分块传输
- 采用缓冲控制避免大量数据造成卡顿

适用场景：

- 手机向电脑发送照片、视频、文档
- 电脑与手机临时互传小文件
- 无需额外后端服务的快速文件交换

### 3. 小说阅读器：`reader.html`

这是一个本地小说阅读工具，支持导入 `.txt` 文件，并以章节方式展示内容，适合手机端或本地阅读。

核心能力：

- 导入本地小说文本文件
- 自动识别章节标题并拆分章节
- 提供上一章/下一章切换
- 支持目录快速跳转
- 支持字号调节与深色模式
- 使用 IndexedDB 保存书架和阅读进度

技术实现：

- 使用 IndexedDB 持久化小说数据与进度
- 通过文本规则识别常见章节标题
- 对小说正文按段落进行展示
- 记录当前阅读章节，重新打开时恢复进度

适用场景：

- 本地小说管理
- 断点续读
- 轻量在线阅读体验

### 4. 共享标点地图：`marker.html`

这是一个基于地图的标点工具，适合记录常用地点、旅行路线或团队共享地理信息。

核心能力：

- 在地图上添加和展示标注点
- 支持按类别筛选与搜索
- 支持新增类型与颜色定义
- 查看地点详情并生成导航链接
- 打开页面后自动定位到当前位置附近
- 默认在中国区域内进行地图展示与定位

技术实现：

- 使用 Leaflet 渲染地图与标记
- 优先使用浏览器 Geolocation API 获取高精度定位（GPS/WiFi，米级），失败时自动降级为 IP 定位（城市级，仅参考）
- IP 定位内置多源公共接口依次降级：ipwho.is → GeoJS → ipapi.co → ipinfo.io → freeipapi.com，单一接口失效不影响定位
- 所有定位坐标经 WGS84 → GCJ02 转换后匹配高德底图
- 通过本地/远程 JSON 数据维护类型和标点
- 结合浏览器能力实现轻量数据管理

适用场景：

- 旅行规划与出行路线记录
- 归档餐厅、景点、停车点等地点
- 共享常用地点信息

### 5. 照片工坊：`photo.html`

这是一个浏览器端图片处理工具，可对上传的照片进行切分、加注水印并导出。

核心能力：

- 上传本地图片进行编辑
- 按行列将图片切分为多个分格
- 支持添加文字水印并调节透明度
- 分格结果打包为 ZIP 导出（每格一张图）

技术实现：

- 使用 JSZip 在浏览器端完成打包导出
- 基于 Canvas 完成切分与水印绘制
- 全程本地处理，图片不上传服务器

适用场景：

- 九宫格切图发布社交平台
- 批量为照片加注水印

### 6. 加密记录：`vault.html`

这是一个本地加密笔记工具，用于安全保存密码、银行卡信息等敏感文本。

核心能力：

- 以密码派生密钥对记录内容进行加密保存
- 支持多行文本记录的新增、查看与解密
- 数据加密后持久化在浏览器本地，明文不出本机

技术实现：

- 采用 Web Crypto API 的 AES-256-GCM 加密
- 基于用户密码派生密钥，验证通过后方可解密
- 使用本地存储保存密文记录

适用场景：

- 个人密码、账号等敏感信息的本地保管
- 不依赖云端、注重隐私的随手加密记事

### 7. 戒烟日志：`quit.html`

这是一个戒烟打卡与激励工具，帮助记录戒烟时长并量化戒烟收益。

核心能力：

- 记录戒烟开始时间并持续计时
- 展示已戒烟天数与下一里程碑天数
- 统计未吸烟支数与省下的烟费
- 深浅色模式适配

技术实现：

- 使用 dayjs 处理时间计算
- 数据保存在浏览器本地，重新打开自动续算
- 按用户设置的每日吸烟量与烟价估算节省金额

适用场景：

- 戒烟过程中的自我激励与进度追踪

### 8. 拼图游戏：`puzzle.html`

这是一个本地图片拼图小游戏。

核心能力：

- 上传本地图片，按原比例切分为拼块
- 自动打乱拼块顺序，并保证不会出现开局即完成的状态
- 交互还原图片，锻炼观察力

技术实现：

- 基于 Canvas 完成图片切块与渲染
- 全程浏览器本地处理，无需上传

适用场景：

- 休闲小游戏
- 用自己的照片制作定制拼图

### 9. 二维码生成器：`qrcode.html`

这是一个本地二维码生成工具，输入内容即时生成二维码图片。

核心能力：

- 输入文本内容即时生成二维码预览
- 生成结果可直接下载保存为图片
- 对内容长度进行容量上限校验（按 UTF-8 字节数），超长时给出精简提示

技术实现：

- 引入二维码生成库，渲染到 Canvas 后供预览与下载
- 全部在浏览器本地生成，内容不会上传服务器

适用场景：

- 快速把链接、文本转为二维码
- 无需联网上传的隐私敏感内容转码

### 10. 每日提醒：`warn.html`

这是一个浏览器端定时提醒工具，用于维护一组提醒事项并在到达时间时发出通知。

核心能力：

- 维护提醒列表，设置提醒内容与提醒时间
- 支持每日循环提醒
- 到点时通过浏览器通知弹出提醒，并辅以提示音
- 深浅色模式适配

技术实现：

- 使用 Notification API 发送浏览器通知，权限静默申请，不打断页面
- 使用 Web Audio 合成提示音，无需加载音频文件
- 提醒数据保存在 localStorage，刷新页面后仍然生效
- 内置触发容错窗口，避免因页面休眠错过提醒

适用场景：

- 喝水、起身、待办事项等周期性提醒
- 不想安装额外 App 的轻量定时提醒

### 11. 流体模拟：`fluid.html`

这是一个 WebGL 流体模拟交互演示页，属于趣味视觉实验性质的工具页。

核心能力：

- 全屏流体动画，鼠标或触摸滑动即可搅动流体
- 多点触控支持，手机上同样流畅
- 无任何操作门槛，打开即玩

技术实现：

- 引入 WebGL 流体模拟库，基于 GPU 着色器实时求解流体方程
- 不涉及数据存储，纯视觉交互演示

适用场景：

- 休闲解压、视觉演示
- WebGL 性能与效果参考

### 12. 意见反馈：`feedback.html`

这是项目的意见反馈入口页，用于收集用户提交的问题、建议等反馈。

核心能力：

- 提供反馈类型选择（问题 / 建议 / 其他）与多行反馈内容输入
- 记录反馈来源页面，便于定位问题
- 提交后给出成功/失败状态提示

技术实现：

- 反馈通过 GitHub 仓库的文件接口提交保存，无需自建后端
- 提交前进行内容校验，避免空反馈

适用场景：

- 用户向项目维护者提交问题或改进建议
