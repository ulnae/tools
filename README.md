# 工具箱

一个纯前端的静态工具集合，面向日常使用场景，集中展示一组轻量、实用、无需后端服务的网页工具。项目以 `index.html` 作为入口，提供多项工具的快捷入口，并通过浏览器本地能力完成数据处理、存储和交互。

> 说明：本文档聚焦项目的正式功能页，不包含 `*-admin.html` 管理后台页面的说明与介绍。这些管理页属于内部管理/运维入口，不是面向普通用户的主功能页面。

## 项目定位

该仓库本质上是一个“工具集入口站”，并非传统业务系统，而是一个适合前端演示和浏览器 API 实践的静态站点。它的设计目标是：

- 纯前端实现，无需部署后端服务
- 轻量启动，适合本地或静态托管运行
- 面向移动端和桌面端双平台适配
- 以小而实用的工具为核心，降低上手门槛

## 主要功能

### 1. 入口首页：`index.html`

这是整个项目的主入口。首页采用现代化的卡片式布局，展示一组常用工具入口，并结合日期、农历和时辰信息增强展示效果。

主要特点：

- 以工具卡片方式集中展示各功能入口
- 支持浅色/深色模式自动切换
- 适配手机端和桌面端布局
- 通过静态页面实现轻量导航中心

### 2. 文件传输助手：`transfer.html`

这是一个基于 WebRTC 的点对点文件传输工具，可以在同一局域网或通过稳定连接环境下，进行电脑和手机之间的文件直传。

核心能力：

- 电脑 ↔ 手机直接建立 P2P 连接
- 不依赖服务器中转，文件在浏览器端直传
- 支持多文件选择与拖拽上传
- 传输中显示进度与状态信息
- 接收后可直接下载保存

技术实现：

- 使用 PeerJS 封装 WebRTC 连接
- 通过二维码或手动输入 ID 建立连接
- 使用 `File`、`Blob` 与 `ArrayBuffer` 处理分块传输
- 采用缓冲控制避免大量数据造成卡顿

适用场景：

- 手机向电脑发送照片、视频、文档
- 电脑与手机临时互传小文件
- 无需额外后端服务的快速文件交换

### 3. 小说阅读器：`reader.html`

这是一个本地小说阅读工具，支持导入 `.txt` 文件，并以章节方式展示内容，适合手机端或本地阅读。

核心能力：

- 导入本地小说文本文件
- 自动识别章节标题并拆分章节
- 提供上一章/下一章切换
- 支持目录快速跳转
- 支持字号调节与深色模式
- 使用 IndexedDB 保存书架和阅读进度

技术实现：

- 使用 IndexedDB 持久化小说数据与进度
- 通过文本规则识别常见章节标题
- 对小说正文按段落进行展示
- 记录当前阅读章节，重新打开时恢复进度

适用场景：

- 本地小说管理
- 断点续读
- 轻量在线阅读体验

### 4. 共享标点地图：`marker.html`

这是一个基于地图的标点工具，适合记录常用地点、旅行路线或团队共享地理信息。

核心能力：

- 在地图上添加和展示标注点
- 支持按类别筛选与搜索
- 支持新增类型与颜色定义
- 查看地点详情并生成导航链接
- 默认在中国区域内进行地图展示与定位

技术实现：

- 使用 Leaflet 渲染地图与标记
- 通过本地/远程 JSON 数据维护类型和标点
- 支持地图视图交互、定位和导航跳转
- 结合浏览器能力实现轻量数据管理

适用场景：

- 旅行规划与出行路线记录
- 归档餐厅、景点、停车点等地点
- 共享常用地点信息

### 5. 其他实用工具

项目中还包含一组辅助型工具页，主要为浏览器端常用小功能，便于独立使用：

- `qrcode.html`：二维码生成工具
- `warn.html`：提醒/提醒事项页面
- `fluid.html`：可能为测试或特定交互页
- `feedback.html`：意见反馈入口页

这些页面都按“轻量工具”思路实现，保持了与项目整体一致的前端静态特性。
